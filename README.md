# Oman Weather & GPS Live

A web app for exploring weather and location information across Oman.

## Overview
This project brings weather information and an interactive map into one interface, allowing users to explore locations across Oman.

## Features
- Weather information for selected locations
- Interactive map with location coordinates
- “Use My Location” option, with user permission

## Development
Built with assistance from Google AI Studio as part of my practical learning in web application development and data presentation.

## Project Status
Prototype under development. Weather accuracy and location features are still being evaluated.
